# Funniest Excuse for Skipping a Meeting

Entry for the make.fun competition
`u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163`.

One razor-sharp line (134 characters) that gets you out of a pointless
meeting — no bad wifi, no cat, no dentist:

> I have to skip this one — I've already attended it three times in my head, and in every version we still end with 'let's circle back.'

## How to run

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` and prints it to stdout.
